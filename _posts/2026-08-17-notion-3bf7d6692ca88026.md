```javascript

```

클로드 시작

```javascript

```

```javascript
/init
```

*/init 명령어를 실행하면 프로젝트 분석을 돕는* *`claude.md`* *파일이 자동 생성된다.*

# 3가지 작동 모드

*shift - tab 을 통해서 변동 가능*

  - ***Default Mode:*** *파일을 수정할 때마다 사용자에게 승인을 요청하는 기본 모드*
  - ***Auto-accept Mode:*** *매번 묻지 않고 자동으로 파일을 수정하는 모드*
  - ***Plan Mode:*** *코드를 즉시 작성하지 않고, 먼저 문제를 분석하고 해결 계획을 세우는 모드. 복잡한 기능을 구현할 때 유용*

# 세션 관리

```javascript
# 대화 이력 관리
/clear           # 대화 이력 삭제
/compact         # 컨텍스트 압축 (긴 세션에서 토큰 절약)
/compact "Spring Boot 관련 내용으로 압축해줘"

# 세션 저장/재개
/rename "세션이름"   # 세션 이름 변경
/branch          # 현재 지점에서 새 분기 생성

# 백그라운드 실행
claude --background "GitHub PR 리뷰해줘" &

# 상태 확인
/status          # 계정, 시스템 상태 확인
```

# 코드 리뷰 및 분석

```javascript
# 코드 리뷰 요청
/review          # 현재 파일 리뷰

# Spring Boot 성능 분석
/effort          # 현재 작업의 난이도/예상 비용 보기

# 도움말
/help            # 모든 명령어 보기
```
