```kotlin
@SpringBootApplication
class Application

fun main(args: Array<String>) {
    println("시작합니다.")
    SpringApplication.run(Application::class.java, *args)
}
```

## main 함수

Java와 다르게 Kotlin에서는 main 함수를 클래스 밖에 독립적으로 선언 가능하다(Top-level Function)

## Application::class.java 

`Application::class` = Kotlin 리플렉션으로 클래스 참조

`.java` = Java의 `Class` 객체로 변환 (Spring이 Java 기반이라서 필요)
