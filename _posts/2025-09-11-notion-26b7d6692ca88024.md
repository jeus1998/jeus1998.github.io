# 스프링 S3 환경별 설정 가이드

## 1. build.gradle 의존성 추가

```
dependencies {
    implementation platform('io.awspring.cloud:spring-cloud-aws-dependencies:3.1.1')
    implementation 'io.awspring.cloud:spring-cloud-aws-starter-s3'
    implementation 'org.springframework.boot:spring-boot-starter-web'

    testImplementation 'org.springframework.boot:spring-boot-starter-test'
}

```

## 2. application.yml 환경별 설정

### application.yml (공통)

```yaml
spring:
  profiles:
    active: local
  cloud:
    aws:
      region:
        static: ap-northeast-2
        auto: false
      stack:
        auto: false

logging:
  level:
    io.awspring.cloud: DEBUG

```

### application-local.yml

```yaml
spring:
  cloud:
    aws:
      credentials:
        access-key: your-access-key
        secret-key: your-secret-key
      s3:
        bucket: your-test-bucket-name
        region: ap-northeast-2

s3:
  bucket-name: your-test-bucket-name

```

### application-prod.yml

```yaml
spring:
  cloud:
    aws:

        access-key: your-access-key
```

## 6. 실제 S3 서비스 구현

```java
@Service
@Profile("!test")  // 테스트 환경이 아닐 때만 활성화
@RequiredArgsConstructor
@Slf4j
public class S3ServiceImpl implements S3Service {

    private final S3Client s3Client;
    private final S3Properties s3Properties;

    @Override
    public String uploadImage(MultipartFile file, String directory) {
        try {
            String fileName = generateFileName(file.getOriginalFilename());
            String key = directory + "/" + fileName;

            PutObjectRequest putObjectRequest = PutObjectRequest.builder()
                    .bucket(s3Properties.getBucketName())
                    .key(key)
                    .contentType(file.getContentType())
                    .contentLength(file.getSize())
                    .build();

            s3Client.putObject(putObjectRequest,
                    RequestBody.fromInputStream(file.getInputStream(), file.getSize()));

            log.info("이미지 업로드 성공: {}", key);
            return getImageUrl(key);

        } catch (Exception e) {
            log.error("이미지 업로드 실패", e);
            throw new RuntimeException("이미지 업로드에 실패했습니다.", e);
        }
    }

    @Override
    public void deleteImage(String imageUrl) {
        try {
            String key = extractKeyFromUrl(imageUrl);

            DeleteObjectRequest deleteObjectRequest = DeleteObjectRequest.builder()
                    .bucket(s3Properties.getBucketName())
                    .key(key)
                    .build();

            s3Client.deleteObject(deleteObjectRequest);
            log.info("이미지 삭제 성공: {}", key);

        } catch (Exception e) {
            log.error("이미지 삭제 실패: {}", imageUrl, e);
            throw new RuntimeException("이미지 삭제에 실패했습니다.", e);
        }
    }

    @Override
    public String getImageUrl(String key) {
        return String.format("https://%s.s3.%s.amazonaws.com/%s",
                s3Properties.getBucketName(), "ap-northeast-2", key);
    }

    private String generateFileName(String originalFilename) {
        String extension = originalFilename.substring(originalFilename.lastIndexOf("."));
        return UUID.randomUUID().toString() + extension;
    }

    private String extractKeyFromUrl(String imageUrl) {
        // URL에서 키 추출 로직
        String baseUrl = String.format("https://%s.s3.ap-northeast-2.amazonaws.com/",
                s3Properties.getBucketName());
        return imageUrl.replace(baseUrl, "");
    }
}

```

## 7. 테스트용 모킹 서비스

```java
@Service
@Profile("test")  // 테스트 환경에서만 활성화
@RequiredArgsConstructor
@Slf4j
public class MockS3Service implements S3Service {

    private final S3Properties s3Properties;
    private final Map<String, String> mockStorage = new ConcurrentHashMap<>();

    @Override
    public String uploadImage(MultipartFile file, String directory) {
        try {
            String fileName = generateFileName(file.getOriginalFilename());
            String key = directory + "/" + fileName;
            String mockUrl = "https://mock-s3-url.com/" + key;

            // 모킹용 저장소에 저장
            mockStorage.put(key, mockUrl);

            log.info("모킹 이미지 업로드 성공: {}", key);
            return mockUrl;

        } catch (Exception e) {
            log.error("모킹 이미지 업로드 실패", e);
            throw new RuntimeException("이미지 업로드에 실패했습니다.", e);
        }
    }

    @Override
    public void deleteImage(String imageUrl) {
        String key = extractKeyFromMockUrl(imageUrl);
        mockStorage.remove(key);
        log.info("모킹 이미지 삭제 성공: {}", key);
    }

    @Override
    public String getImageUrl(String key) {
        return mockStorage.getOrDefault(key, "https://mock-s3-url.com/" + key);
    }

    private String generateFileName(String originalFilename) {
        String extension = originalFilename.substring(originalFilename.lastIndexOf("."));
        return UUID.randomUUID().toString() + extension;
    }

    private String extractKeyFromMockUrl(String mockUrl) {
        return mockUrl.replace("https://mock-s3-url.com/", "");
    }
}

```

## 8. 컨트롤러 예시

```java
@RestController
@RequestMapping("/api/images")
@RequiredArgsConstructor
@Slf4j
public class ImageController {

    private final S3Service s3Service;

    @PostMapping("/upload")
    public ResponseEntity<Map<String, String>> uploadImage(
            @RequestParam("file") MultipartFile file,
            @RequestParam(value = "directory", defaultValue = "images") String directory) {

        if (file.isEmpty()) {
            return ResponseEntity.badRequest().build();
        }

        try {
            String imageUrl = s3Service.uploadImage(file, directory);

            Map<String, String> response = new HashMap<>();
            response.put("imageUrl", imageUrl);
            response.put("message", "이미지 업로드 성공");

            return ResponseEntity.ok(response);

        } catch (Exception e) {
            log.error("이미지 업로드 실패", e);
            return ResponseEntity.status(HttpStatus.INTERNAL_SERVER_ERROR).build();
        }
    }

    @DeleteMapping
    public ResponseEntity<Map<String, String>> deleteImage(@RequestParam("imageUrl") String imageUrl) {
        try {
            s3Service.deleteImage(imageUrl);

            Map<String, String> response = new HashMap<>();
            response.put("message", "이미지 삭제 성공");

            return ResponseEntity.ok(response);

        } catch (Exception e) {
            log.error("이미지 삭제 실패", e);
            return ResponseEntity.status(HttpStatus.INTERNAL_SERVER_ERROR).build();
        }
    }
}

```

## 주요 포인트

1. **프로필 기반 환경 분리**: `@Profile` 어노테이션으로 환경별 빈 생성 제어
1. **공통 인터페이스**: `S3Service` 인터페이스로 실제 구현과 모킹 구현 통일
1. **설정 외부화**: `application-{profile}.yml`로 환경별 설정 분리
1. **보안 설정 동일**: 로컬과 운영은 같은 AWS 접근 설정 사용
1. **모킹 서비스**: 테스트 환경에서는 실제 S3 없이 동작

이렇게 설정하면 환경별로 자동으로 적절한 S3 설정과 서비스가 주입되어 사용됩니다!
