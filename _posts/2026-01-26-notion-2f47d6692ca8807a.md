
## axios를 활용한 데이터 전송

---

```html
<script setup>
import axios from 'axios';

const inputData = () => {
  axios
    .post('http://localhost:3000/member', {
      name: 'kang',
      email: 'kang@gmail.com',
    })
    .then((res) => {
      console.log(res);
    });
};
</script>

<template>
  <button @click="inputData">데이터 입력</button>
</template>
```

- ***axios는 비동기적으로 동작한다***
