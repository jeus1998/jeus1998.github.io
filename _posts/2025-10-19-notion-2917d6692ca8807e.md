# precision & scale

```kotlin
@Column(name = "balance", nullable = false, precision = 15, scale = 2)
var balance: BigDecimal = BigDecimal.ZERO,
```

  - 데이터베이스 DECIMAL / NUMERIC 타입에서 사용하는 개념
  - precision(정밀도): 전체 자릿수
  - scale(스케일): 소수점 이하 자릿수

***즉, precision: 15 scale: 2는 정수 부분은 최대 13자리 소수점 이하는 2자리***

# Kotlin Data Class 상세 설명

**자동 생성되는 메서드**

```kotlin
data class User(
    val name: String,
    val age: Int
)
-------------------------------------------------------------------------
**아래 메서드들이 자동 생성**
*1. equals() / hashCode()
2. toString()
3. copy()
4. componentN()*
```

**copy()**

불변 객체의 일부 속성만 변경한 복사본을 쉽게 만들 수 있다.

```kotlin
val user = User("Alice", 25)
val olderUser = user.copy(age = 26)  *// name은 그대로, age만 변경*

println(user)       *// User(name=Alice, age=25)*
println(olderUser)  *// User(name=Alice, age=26)*
```

**destructing(구조 분해)**

componentN() 함수들이 자동 생성되어 구조 분해가 가능하다.

```kotlin
val user = User("Alice", 25)
val (name, age) = user  *// component1(), component2() 호출*

println(name)  *// Alice*
println(age)   *// 25*
```

**Data Class 제약사항**

  1. **주 생성자에 최소 1개의 파라미터 필요**
  1. **주 생성자의 파라미터는 val 또는 var이어야 함**
  1. **abstract, open, sealed, inner 클래스가 될 수 없다**

```kotlin
// 불가능
data class Empty()  // 파라미터 없음

// 불가능
data class Wrong(name: String)  // val/var 없음

// 가능
data class Correct(val name: String)
```
