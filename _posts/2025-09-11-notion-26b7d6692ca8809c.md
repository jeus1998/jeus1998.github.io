# 핵심 아이디어

```
DP 배열을 0번집을 선택 가능한 경우와 아닌 경우로 나눈다. -> 원형이기 때문에

점화식
int [][] dp = new int [2][n];

dp[0][?] = 0번집 선택이 가능한 경우
dp[1][?] = 0번집 선택이 불가능한 경우

?: 해당 번수 집을 선택하는 경우에 최댓값
```
