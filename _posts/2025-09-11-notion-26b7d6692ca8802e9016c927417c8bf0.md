# 자주 사용하는 명령어 

**컨테이너 접속** 

```bash
docker exec -it [컨테이너 ID] bash
```

**redis cli 실행** 

```bash
docker exec -it [redis 컨테이너 ID] redis-cli

-----------------------------------------------------
docker exec -it [redis 컨테이너 ID] bash
redis-cli
```

- 물론 컨테이너를 접속해서 내부에서 실행하는 방식도 가능

**mysql 실행** 

```bash
docker exec -it [mysql 컨테이너 ID] mysql -u root -p 

-----------------------------------------------------
docker exec -it [mysql 컨테이너 ID] bash
mysql -u root -p
```

- 물론 컨테이너를 접속해서 내부에서 실행하는 방식도 가능

**여러가지 옵션** 

```bash
--name: 
컨테이너 이름 붙이기 

-d: 
백그라운드 스레드로 실행 

-p: 
host 포트, 컨테이너 포트 매핑

-f: 
force 

-i: 
"interactive" 모드로 컨테이너와 상호작용할 수 있도록 한다. 입력을 받을 수 있게 한다.

-t: 
"tty" (터미널)를 할당하여 가상 터미널을 제공. 
이는 컨테이너 내에서 명령어를 실행할 때 마치 실제 터미널을 사용하는 것처럼 보이게 해준다

-v:
볼륨 설정 [호스트 경로]:[컨테이너 경로]
```

 **로그** 

```bash
# 실시간 로그 
docker logs -f [컨테이너 ID]

# 로그 
docker logs [컨테이너 ID]

# 로그 원하는 길이(10)
docker logs --tail 10 [컨테이너 ID]

# 응용: 이전 로그 X & 실시간 로그 
docker logs -f --tail 0 [컨테이너 ID]
```

**자주 사용하는 명령어** 

```bash
# 실행중인 컨테이너 
docker ps 

# 모든 컨테이너 조회 
docker ps -a 

# 컨테이너 실행 
docker start [컨테이너 ID]

# 컨테이너 중지
docker stop [컨테이너 ID]

# 컨테이너 강제 중지 (컴퓨터 렉걸려서 강제 종료)
docker kill [컨테이너 ID]

# 컨테이너 삭제
docker rm [컨테이너 ID]

# 실행중인 컨테이너 삭제
docker rm -f [컨테이너 ID]

# 이미지 조회 
docker image ls 

# 이미지 삭제
docker rmi [이미지 ID]

# 이미지 다운 이미지이름:테그 (테그 생략하면 latest)
docker pull redis 

# 실행(이미지 없으면 다운하고 실행)
docker run redis 

# 백그라운드 실행 
docker run -d redis

# host, container 포트 맵핑 
docker run -p 6379:6379 redis

# 컨테이너 이름 붙이기
docker run --name redis 

# 특정 포트 사용하고 있는 프로세스 조회
sudo lsof -i:3306

# 프로세스 강제 종료
kill [PID]

# 환경 변수 출력 
echo $MYSQL_ROOT_PASSWORD

# 이미지 생성 (Dockerfile 존재하는 경로 기준)
docker build -t [이미지 NAME]:[이미지 TAG] . 

# 파일 복사(로컬 -> 컨테이너)
docker cp <로컬 경로> <컨테이너 이름 또는 ID>:<컨테이너 내부 경로>
```

# 이미지 생성

**Dockerfile** 

```yaml
# 파일 복사
COPY app.txt /app.txt

# 디렉터리 복사
COPY my-app /my-app/

# txt 확장자 파일 전부 복사
COPY *.txt /text-files/

# 전부 복사
COPY ./ /

# 500초 동안 시스템을 일시정지 시키는 명령어
ENTRYPOINT ["/bin/bash", "-c", "sleep 500"]

ENTRYPOINT ["java", "-jar", "/app.jar"]
```

- **.dockerignore 사용 가능**

**RUN : 이미지를 생성하는 과정에서 사용할 명령문 실행**

```yaml
FROM ubuntu

RUN apt update && apt install -y git

ENTRYPOINT ["/bin/bash", "-c", "sleep 500"]
```
