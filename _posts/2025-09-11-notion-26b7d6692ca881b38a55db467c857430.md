# **UserDetails**

- 사용자의 기본 정보를 저장하는 인터페이스로서 Spring Security 에서 사용하는 사용자 타입이다 
- 저장된 사용자 정보는 추후에 인증 절차에서 사용되기 위해 `Authentication`객체에 포함되며 구현체로 `User` 클래스가 제공된다
