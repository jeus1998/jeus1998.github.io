{% raw %}## methods 옵션, 사용자 함수/ 메서드 만들기

---

```html
<script>
export default {
  methods: {
    greeting() {
      return 'Hi, there' + `My name is ${this.userName}`;
    },
  },
  data() {
    return {
      userName: '왕초보',
    };
  },
};
</script>

<template>
  <h1>{{ greeting() }}</h1>
</template>
```

- *v-on 같은 directive에서는 argument가 없는 경우 greeting 이런식으로 괄호를 생략할 수 있다.*
