# TDD에 대한 오해 

오해: **TDD는 테스트를 하는 것이다**

진실: **TDD는 설계와 개발 하는 것이다** 

# TDD와 SW테스팅의 차이 

**SW 테스팅 VS TDD**

- SW테스팅: 품질 검증 활동 
- TDD: 설계 개발 활동 

# TDD의 Activity 목표 

기능성: 요구사항의 구현 가능섬 검토 

신뢰성: 신뢰있는 응답 구현 

효율성: 언더 엔지니어링 유지 

유지보수성: 사이드 이펙트 배제 

사용성: 개발 편의성 유지 

이식성: 다양한 배포환경 설정 설계

# Spring의 TDD 지원 도구들 

Runner: JUnit

Matcher: Hamcrest

Fluent api: AssertJ

Double, Mock, Sub: Mockito

Json Object: Json Object
