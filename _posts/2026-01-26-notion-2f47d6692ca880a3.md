{% raw %}```html
<script setup>
import { computed, ref } from 'vue';

const cnt = ref(10);
const counter = () => {
  cnt.value++;
};
// 
const oddEven = computed(() => {
  return cnt.value % 2 ? '홀수' : '짝수';
});
</script>

<template>
  <p>cnt: {{ cnt }}</p>
  <p>홀짝 판별: {{ oddEven }}</p>
  <button @click="counter">클릭</button>
</template>
```

- *oddEven 같은 경우 computed를 사용했기 때문에 cnt가 바뀌지 않는다면 아래 계산은 다시하지 않는다.(캐싱)*
