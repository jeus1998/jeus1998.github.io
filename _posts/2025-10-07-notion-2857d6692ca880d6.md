# Challenge 3: Default arguments

**Q: Java에서 'foo()'의 오버로드가 여러 개 있다고 가정해 보겠습니다.**

```java
public String foo(String name, int number, boolean toUpperCase) {
    return (toUpperCase ? name.toUpperCase() : name) + number;
}

public String foo(String name, int number) {
    return foo(name, number, false);
}

public String foo(String name, boolean toUpperCase) {
    return foo(name, 42, toUpperCase);
}

public String foo(String name) {
    return foo(name, 42);
}
```

**Kotlin에서는 이러한 모든 Java 오버로드를 하나의 함수로 대체할 수 있습니다.** 

**foo를 사용하는 코드가 컴파일되도록 foo 함수의 선언을 변경하세요. 기본 인수와 명명된 인수를 사용하세요.**

```kotlin
// 테스트 케이스
fun useFoo() = listOf(
        foo("a"),
        foo("b", number = 1),
        foo("c", toUpperCase = true),
        foo(name = "d", number = 2, toUpperCase = true)
)


fun foo(name: String, number: Int = 42, toUpperCase: Boolean = false): String {
       return (if(toUpperCase) name.uppercase() else name) + number
}
```

number 기본값: 42, toUpperCase 기본값: false

# Challenge 4: Triple-quoted strings

**Q: Kotlin의 다양한 문자열 리터럴과 문자열 템플릿에 대해 알아보세요.
편리한 라이브러리 함수 trimIndent와 trimMargin을 사용하면 여러 줄로 된 삼중 따옴표로 묶인 문자열을 주변 코드에 맞게 서식 지정할 수 있습니다.** 

**이 호출은 접두사 값으로 #을 사용하므로 결과 문자열에 접두사 문자가 포함되지 않습니다.**

```kotlin
const val question = "life, the universe, and everything"
const val answer = 42

val tripleQuotedString = """
    #question = "$question"
    #answer = $answer""".trimIndent()

fun main() {
    println(tripleQuotedString)
}

/* 원하는 결과
question = "life, the universe, and everything"
answer = 42
*/
```

### **trimIndent() 설명**

모든 줄에서 공통적으로 존재하는 앞쪽 공백을 자동으로 감지하여 제거

```kotlin
val text = """
    첫 번째 줄
    두 번째 줄
    세 번째 줄
""".trimIndent()

// 결과:
// 첫 번째 줄
// 두 번째 줄
// 세 번째 줄
```

### trimMargin() 설명

지정된 마진 문자(기본값: `|`)를 기준으로 그 앞의 공백을 제거하는 함수

```kotlin
val text = """
    |첫 번째 줄
    |두 번째 줄
    |세 번째 줄
""".trimMargin()

// 커스텀 마진 문자 사용
val text2 = """
    #첫 번째 줄
    #두 번째 줄
    #세 번째 줄
""".trimMargin("#")
```

### trimIndent 결과

```kotlin
val tripleQuotedString = """
    #question = "$question"
    #answer = $answer""".trimIndent()

/*
#question = "life, the universe, and everything"
#answer = 42
*/
```

앞쪽 공백을 자동제거 → “#” 제거 필요

 

### trimMargin 결과

```kotlin
val tripleQuotedString = """
    #question = "$question"
    #answer = $answer
    """.trimMargin("#")
    

/*
question = "life, the universe, and everything"
answer = 42
*/    
```

마진 문자인 “#”을 포함해서 앞쪽 공백을 제거
