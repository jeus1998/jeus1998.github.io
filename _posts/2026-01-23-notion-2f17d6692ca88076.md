{% raw %}## Composition API?

---

*Vue3에서 새롭게 등장한 함수 기반의 API로 컴포넌트 로직을 유연하게 구성하도록 지원하여 코드의 재사용성과*

*가독성을 높여준다.*

## Composition API VS Options API

---

### Options API

*지금까지 배운 것, 컴포넌트 로직을 data, methods, computed, watch 등의 옵션에 담아서 구분*

### Composition API

*Vue3에서 새로 도입된 방식, 함수형 프로그래밍 스타일과 유사 관련 로직을 setup hook에 정의하여 사용*

*코드 재사용성이 높아져서 큰 프로젝트에 적합하다*

### **Options API 방식**

```html
<script>
export default {
  data: function () {
    return {
      cnt: 0,
    };
  },
  computed: {
    oddEven() {
      return this.cnt % 2 ? '홀수' : '짝수';
    },
  },
  methods: {
    counter() {
      this.cnt++;
    },
  },
};
</script>

<template>
  <p>{{ cnt }}</p>
  <p>홀짝 판별 : {{ oddEven }}</p>
  <button @click="counter">클릭</button>
</template>
```

### Composition API 방식1

```html
<script>
import { ref, computed } from 'vue';
export default {
  setup() {
    const cnt = ref(0);
    const oddEven = computed(() => (cnt.value % 2 ? '홀수' : '짝수'));
    const counter = () => cnt.value++;

    return {
      cnt,
      oddEven,
      counter,
    };
  },
};
</script>

<template>
  <p>{{ cnt }}</p>
  <p>홀짝 판별 : {{ oddEven }}</p>
  <button @click="counter">클릭</button>
</template>
```

### Composition API 방식2

```html
<script setup>
import { ref, computed } from 'vue';

const cnt = ref(0);
const oddEven = computed(() => (cnt.value % 2 ? '홀수' : '짝수'));
const counter = () => cnt.value++;

</script>

<template>
  <p>{{ cnt }}</p>
  <p>홀짝 판별 : {{ oddEven }}</p>
  <button @click="counter">클릭</button>
</template>
```
