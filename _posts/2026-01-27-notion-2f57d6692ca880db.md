{% raw %}*리다렉션하거나 취소하여 네비게이션을 보호하는 용도로 사용*

1. *전역적으로 적용하는 가드*
1. *로그인 여부 체크*
  1. *권한(관리자 / 사용자) 체크*
1. *컴포넌트에 적용하는 가드*
1. *라우터에 적용하는 가드*

***전역 가드는 전체 통제, 라우트 가드는 페이지 단위 통제, 컴포넌트 가드는 화면 단위 통제다.***

## 전역 가드

---

***router/index.js*** 

```javascript
const router = createRouter({
  history: createWebHistory('/'),
  routes,
});

// 전역 가드
router.beforeEach((to, from, next) => {
  console.log(to);
  console.log(from);
  if(to.fullPath !== '/company') {
    next();
  }
});
```

- *사용 방법 next()를 조건부로 호출하여 접근을 막는다.*
- */company를 제외하고는 모두 접근이 가능하다.*

## 컴포넌트 가드

---

```javascript
<script setup>
import { useRouter, onBeforeRouteLeave } from 'vue-router';

onBeforeRouteLeave((to, from, next) => {
  console.log('onBeforeRouteLeave');
  if (to.fullPath !== '/company') {
    next();
  }
});
</script>
```

- *onBeforeRouteLeave를 import 받는다.*
- *사용법은 전역 가드와 동일 해당 가드는 현재 컴포넌트에서 다른 컴포넌트로 넘어갈 때 호출된다.*

## 라우터 가드

---

```javascript
{
  path: '/about',
  name: 'AboutPage',
  alias: '/aboutMe',
  component: AboutView,
  beforeEnter: (to, from, next) => {
    console.log('라우터별 가드 : beforeEnter');
    next()
  }
},
```

- 특정 라우트만 보호
- 관리자 페이지
- 로그인 페이지 접근 제한
