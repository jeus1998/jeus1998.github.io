{% raw %}# SUBSTR - 문자열 추출

```javascript
SUBSTR(문자열, 시작위치, 길이)
```

***문자열 위치는 1부터 시작한다.***

```javascript
SUBSTR('ABCDEFG', 2, 3)

결과: BCD
```

***세 번째 인자인 길이를 생략하면 끝까지 가져온다.*** 

```javascript
SUBSTR('ABCDEFG', 4)

결과: DEFG
```

***음수 위치***

```javascript
 A B C D E F G
 1 2 3 4 5 6 7

-7-6-5-4-3-2-1
```

```javascript
SUBSTR('ABCDEFG', -3, 2)

결과: EF
```

# LENGTH - 문자열 길이

```javascript
LENGTH(문자열)
```

```javascript
LENGTH('ABCDE')

결과: 5
```

Oracle LENGTHB 함수 같은 경우 문자 수가 아니라 바이트 수를 구한다.

# INSTR - 문자열 위치 찾기

```javascript
INSTR(문자열, 찾을문자열 [, 시작위치 [, 몇번째]])
```

```javascript
INSTR('ABCDEFG', 'D')

결과: 4
```

```javascript
INSTR('ABABAB', 'A', 1, 2)

결과: 3
```

# LPAD - 왼쪽 채우기 / RPAD - 오른쪽 채우기

```javascript
LPAD(문자열, 전체길이, 채울문자)
```

```javascript
LPAD('ABC', 7, 'XY')

결과: XYXYABC
```

***지정 길이가 원래 문자열보다 작으면?***

```javascript
LPAD('ABCDEFG', 3, '0')

결과: ABC
```

→ LPAD 두 번째 인자는 추가할 문자의 개수가 아니라 최종 길이이다.

# LTRIM / RTRIM - 문자 제거

```javascript
LTRIM('000123', '0')
→ 123
```

***인자를 생략하면 기본적으로 공백을 제거한다.***

```javascript
LTRIM('   ABC')
→ ABC

RTRIM('ABC   ')
→ ABC
```

### 주의할 점

***두 번째 인자를 하나의 문자열 덩어리로 생각하면 안된다.***

```javascript
LTRIM('ABBAZACD', 'AB')
-> ZACD
```

AB 라는 문자열을 찾는 게 아니라 A 또는 B에 해당하는 문자를 왼쪽에서 계속 제거한다.

# TRIM - 양쪽 제거

```javascript
TRIM('   ABC   ')
→ ABC

TRIM('X' FROM 'XXXABCXXX')
→ ABC

TRIM('   A B C   ')
→ 'A B C'
```

# REPLACE - 문자열 치환

```javascript
REPLACE(문자열, 찾을문자열, 변경문자열)
```

```javascript
REPLACE('ABCABC', 'A', 'X')
→ XBCXBC

REPLACE('ABCABC', 'AB', 'XY')
→ XYCXYC
```

***세번째 인자를 생략한다면?***

```javascript
REPLACE('ABCABC', 'A')
→ BCBC
```

# LOWER / UPPER / INITCAP - 대소문자 변환

```javascript
LOWER('ABC')
→ abc

UPPER('abc')
→ ABC

INITCAP('hello world')
→ Hello World
```

INITCAP 같은 경우 각 단어의 첫 글자를 대문자로 만든다.

# CONCAT / || — 문자열 연결

```javascript
CONCAT('ABC', 'DEF')
→ ABCDEF


'ABC' || 'DEF'
→ ABCDEF


'이름: ' || '철수'
→ 이름: 철수
```
