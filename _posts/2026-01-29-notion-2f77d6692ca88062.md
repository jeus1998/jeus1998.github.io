## @EqualsAndHashCode(callSuper = true)

---

*@EqualsAndHashCode(callSuper = true)는 상속 구조에서 equals / hashCode 범위를 어디까지 볼 거냐를 정하는 옵션*

*default: false, 현재 클래스의 필드로만 비교*

*즉, true인 경우 부모 필드까지 포함해서 equals, hashcode를 자동 생성한다.*

## @SuperBuilder

---

### 빌더의 한계

```java
@Builder
class Parent {
    String name;
}

@Builder
class Child extends Parent {
    int age;
}
```

- *Child.builder()에서 Parent 필드(name)를 못 씀*

```java
@SuperBuilder
class Parent {
    String name;
}

@SuperBuilder
class Child extends Parent {
    int age;
}


Child child = Child.builder()
    .name("kim")   // 부모 필드
    .age(20)       // 자식 필드
    .build();
```

*부모 · 자식 클래스 모두에 @SuperBuilder를 선언해야 자식에서 정상적으로 사용할 수 있다.*

*이 경우 부모 필드에 대한 값도 빌더 패턴을 활용해 생성이 가능하다*
