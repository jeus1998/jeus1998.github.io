### ✅ 케이스 1: WHERE 조건에서 문자 = 숫자 (성공)

Oracle & SQL Server 모두 동일하게 작동

```sql
-- 케이스 1-1: 성공 (묵시적 형변환 일어남)
SELECT * FROM emp WHERE emp_id = 1;
-- 결과: emp_id = '001' 행 반환
-- emp_id가 '1' 또는 '001'로 변환되어 비교

-- 케이스 1-2: 성공 (명시적 형변환 권장)
SELECT * FROM emp WHERE emp_id = '1';
-- 결과: emp_id = '001' 행 반환 (Oracle은 자동 형변환)

-- 케이스 1-3: 실패 가능성 높음
SELECT * FROM emp WHERE emp_id = 1;
-- ABC는 숫자로 변환할 수 없어 무시됨
```

### ❌ 케이스 2: CASE WHEN에서 문자 WHEN 숫자 (에러)

Oracle - 에러 발생

```sql
-- ❌ 에러 발생!
SELECT emp_id,
       CASE emp_id
           WHEN 1 THEN '직급1'
           WHEN 2 THEN '직급2'
           WHEN 3 THEN '직급3'
           ELSE '기타'
       END AS grade
FROM emp;

-- 에러: ORA-00932: inconsistent datatypes: expected CHAR got NUMBER
```

SQL Server - 에러 발생

```sql
-- ❌ 에러 발생!
SELECT emp_id,
       CASE emp_id
           WHEN 1 THEN '직급1'
           WHEN 2 THEN '직급2'
           WHEN 3 THEN '직급3'
           ELSE '기타'
       END AS grade
FROM emp;

-- 에러: Conversion failed when converting the varchar value to data type int
```

### ✅ 케이스 3: 올바른 CASE 문 작성법

Oracle - 문자형으로 통일

```sql
-- ✅ 올바른 방법 1: WHEN을 문자로 지정
SELECT emp_id,
       CASE emp_id
           WHEN '1' THEN '직급1'
           WHEN '2' THEN '직급2'
           WHEN '3' THEN '직급3'
           ELSE '기타'
       END AS grade
FROM emp;

-- 결과:
-- emp_id | grade
-- -------|------
-- 001    | 직급1
-- 002    | 직급2
-- 003    | 직급3
-- ABC    | 기타

-- ✅ 올바른 방법 2: CAST로 형변환
SELECT emp_id,
       CASE CAST(emp_id AS NUMBER)
           WHEN 1 THEN '직급1'
           WHEN 2 THEN '직급2'
           WHEN 3 THEN '직급3'
           ELSE '기타'
       END AS grade
FROM emp;

-- 결과:
-- emp_id | grade
-- -------|------
-- 001    | 직급1
-- 002    | 직급2
-- 003    | 직급3
-- ABC    | 기타  (변환 실패하여 ELSE로 처리)
```

SQL Server - 문자형으로 통일

```sql
-- ✅ 올바른 방법 1: WHEN을 문자로 지정
SELECT emp_id,
       CASE emp_id
           WHEN '1' THEN '직급1'
           WHEN '2' THEN '직급2'
           WHEN '3' THEN '직급3'
           ELSE '기타'
       END AS grade
FROM emp;

-- ✅ 올바른 방법 2: CONVERT로 형변환
SELECT emp_id,
       CASE CONVERT(INT, emp_id)
           WHEN 1 THEN '직급1'
           WHEN 2 THEN '직급2'
           WHEN 3 THEN '직급3'
           ELSE '기타'
       END AS grade
FROM emp;
```

### 🔍 케이스 4: 혼합된 데이터 상황

```sql
-- 혼합된 emp 테이블
-- emp_id: '001', '002', '003', 'ABC', '999'

-- ❌ CASE 문자 WHEN 숫자 → 에러
SELECT CASE emp_id
           WHEN 1 THEN 'Match'
           ELSE 'No Match'
       END
FROM emp;

-- ✅ CASE 문자 WHEN 문자 → 성공
SELECT CASE emp_id
           WHEN '1' THEN 'Match'
           WHEN '001' THEN 'Match'
           ELSE 'No Match'
       END
FROM emp;

-- 결과:
-- 001 → Match (WHEN '001' 과 비교)
-- 002 → No Match (WHEN과 일치하는 항목 없음)
-- 003 → No Match
-- ABC → No Match
-- 999 → No Match
```

### 📌 중요한 비교: WHERE vs CASE

| 구분 | WHERE 조건 | CASE 문 |
| --- | --- | --- |
| `emp_id = 1` | ✅ 성공 (묵시적 형변환) | ❌ 에러 |
| `emp_id = '1'` | ✅ 성공 | ✅ 성공 |
| 형변환 방식 | 자동 형변환 발생 | 형변환 없음 |
| 권장 | 명시적 형변환 권장 | **반드시 문자형으로 통일** |
