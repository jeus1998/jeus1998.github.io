{% raw %}# ROUND 함수(반올림)

```javascript
ROUND(숫자, 자릿수)
```

| 함수 | 결과 | 설명 |
| --- | --- | --- |
| ROUND(3.14159, 2) | 3.14 | 소수점 2자리로 반올림 |
| ROUND(3.5) | 4 | 자릿수 생략 시 정수로 반올림 |
| ROUND(1234.5, -1) | 1230 | 음수는 자릿수 앞쪽 반올림 |
| ROUND(1234.5, -2) | 1200 | 백의 자리로 반올림 |

- **양수**: 소수점 이하 자릿수 지정
- **음수**: 정수 부분의 자릿수 지정 (10의 자리, 100의 자리 등)
- **0**: 정수로 반올림

ROUND(123.41, 0 ) = 123

ROUND(123.51, 0 ) = 124

# SIGN 함수(부호 판정)

| 결과 | 의미 |
| --- | --- |
| **1** | 양수 |
| **-1** | 음수 |
| **0** | 0 |

```javascript
SIGN(5)      → 1
SIGN(-5)     → -1
SIGN(0)      → 0
SIGN(3.14)   → 1
SIGN(-0.5)   → -1
```
