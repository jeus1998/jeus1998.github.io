## WorkBook 종류

- HSSWorkBook: .xls (구버전, 2003 이하)
- XSSWorkBook: .xlsx (2007 이상, 가장 많이 사용)
- SXSSWorkBook: 대용량 쓰기용 (메모리 절약)

```java
Workbook wb = new XSSWorkbook();
```

## Excel 다운로드 (파일 생성) 

```java
Workbook wb = new XSSFWorkbook();
Sheet sheet = wb.createSheet("Sheet1");

Row row = sheet.createRow(0);
Cell cell = row.createCell(0);
cell.setCellValue("테스트");

FileOutputStream fos = new FileOutputStream("test.xlsx");
wb.write(fos);
wb.close();
```

sheet.setColumnWidth(0, 5000);      // 컬럼 넓이

## CellStyle

```java
CellStyle style = wb.createCellStyle();
Font font = wb.createFont();
```

### 폰트 설정

```java
font.setBold(true);
font.setFontHeightInPoints((short)12);
font.setFontName("맑은 고딕");
font.setColor(IndexedColors.RED.getIndex());

style.setFont(font);
```

### 정렬

```java
style.setAlignment(HorizontalAlignment.CENTER);
style.setVerticalAlignment(VerticalAlignment.CENTER);
```

### 테두리

```java
style.setBorderTop(BorderStyle.THIN);
style.setBorderBottom(BorderStyle.THIN);
style.setBorderLeft(BorderStyle.THIN);
style.setBorderRight(BorderStyle.THIN);
```

### 배경색

```java
style.setFillForegroundColor(IndexedColors.YELLOW.getIndex());
style.setFillPattern(FillPatternType.SOLID_FOREGROUND);
```

### 줄바꿈

```java
style.setWrapText(true);
```

### 셀에 스타일 적용

```java
cell.setCellStyle(style);
```

## 셀 병합

```java
sheet.addMergedRegion(new CellRangeAddress(
    0, 0,   // 시작행, 끝행
    0, 3    // 시작열, 끝열
));
```

## WorkBook 다 만든 뒤 맨 위에 헤더 추가

### shiftRows 사용

```java
sheet.shiftRows(0, sheet.getLastRowNum(), 1);
```

- 파라미터 설명
- 0: 시작 행
  - sheet.getLastRowNum(): 마지막행
  - 1: 아래로 1칸 밀기

```java
Row header = sheet.createRow(0);
header.createCell(0).setCellValue("헤더");
```

- shift 이후 0번 row 생성

## Excel 업로드 (읽기)

```java
Workbook wb = new XSSFWorkbook(inputStream);
Sheet sheet = wb.getSheetAt(0);

for (Row row : sheet) {
    for (Cell cell : row) {
        switch (cell.getCellType()) {
            case STRING:
                System.out.println(cell.getStringCellValue());
                break;
            case NUMERIC:
                System.out.println(cell.getNumericCellValue());
                break;
        }
    }
}
```
